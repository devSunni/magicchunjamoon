# 준우·지우 마법천자문 한자 급수 수련 PWA (8급~5급 500자)

**바로 실행하기 (PWA):** https://devsunni.github.io/magicchunjamoon/

한국어문회 초등 급수 배정한자 **8급~5급 총 500자**를 마법천자문 세계관으로 즐겁게 수련하는 설치형 오프라인 PWA입니다.

## 주요 기능
- **한국어문회 8급~5급 500자 완비**: 8급(50) · 준7급(50) · 7급(50) · 준6급(75) · 6급(75) · 준5급(100) · 5급(100)
- **마법 배틀 & 오답 두루마리**: 한자 → 훈·음, 훈·음 → 한자, 실전 혼합 모드 및 오답 집중 복습
- **마법진 필순 검증 쓰기**: `hanzi-writer` 기반 500자 전체 획순 검증(한국 정자 이체자 7자 자동 매핑 포함) + 오프라인 자유 필기 폴백
- **한국어 발음 듣기 (이중 TTS 엔진)**: Web Speech API 한국어 음성 자동 선택·충돌 방지 + 미지원/차단 환경 자동 오디오 TTS 폴백
- **승급 시험 & 듀얼 프로필**: 준우/지우 개별 학습 기록(`localStorage`), 순차 해금 및 부모님 전체 해금 모드, 동료 캐릭터 5종

## 폰에 설치 방법
1. 위 주소(https://devsunni.github.io/magicchunjamoon/)로 접속합니다.
2. **Android Chrome / 삼성 인터넷**: 메뉴(⋮) → **앱 설치 / 홈 화면에 추가**
3. **iPhone Safari**: 공유 버튼 → **홈 화면에 추가**
4. **PC Chrome / Edge**: 주소창 오른쪽 **설치** 아이콘 클릭

## 포함된 파일
- `index.html`: 메인 앱 (500자 데이터, 배틀·필순 쓰기·도감·승급시험, 이중 TTS 엔진)
- `manifest.json`: PWA 설치 매니페스트
- `sw.js`: 오프라인 캐싱 서비스 워커
- `icon-192.png`, `icon-512.png`: 홈 화면 앱 아이콘
- `tests/`: Node.js 데이터·로직·PWA 무결성 테스트 (`node --test tests/*.test.js`)
